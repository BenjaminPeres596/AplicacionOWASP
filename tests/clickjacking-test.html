🎯 Prueba de Clickjacking - Diferencias de Configuración

❌ Puerto 3000 (Juice Shop Original - SIN X-Frame-Options)

Esperado: El iframe se carga normalmente - VULNERABLE a clickjacking

🟠 Puerto 8082 (Básico - X-Frame-Options: SAMEORIGIN)

Esperado: El iframe se bloquea porque viene de diferente origen

🟡 Puerto 8081 (Moderado - X-Frame-Options: SAMEORIGIN)

Esperado: El iframe se bloquea

🟢 Puerto 8080 (Ultra-Seguro - X-Frame-Options: DENY)

Esperado: El iframe se bloquea completamente

🔍 Cómo interpretar los resultados:

  • Si el iframe se carga: VULNERABLE a clickjacking
  • Si aparece error/página en blanco: PROTEGIDO contra clickjacking
  • Diferencia SAMEORIGIN vs DENY: SAMEORIGIN permite mismo dominio, DENY bloquea todo
